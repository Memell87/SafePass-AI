O **SafePass AI** é uma ferramenta de desktop moderna e eficiente projetada para criar senhas fortes instantaneamente. O foco principal deste projeto foi unir a segurança de dados com uma interface de utilizador (UI) contemporânea e intuitiva.

## ✨ Funcionalidades

- **Geração Aleatória Segura:** Cria senhas complexas utilizando caracteres alfanuméricos e símbolos.
- **Interface Moderna:** Desenvolvido com `CustomTkinter`, oferecendo um design limpo com suporte nativo ao **Dark Mode**.
- **UX Focada:** Layout organizado para garantir que o utilizador gere a sua senha com apenas um clique.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** [Python 3.x](https://www.python.org/)
* **Interface Gráfica:** [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter) (Biblioteca de UI moderna baseada em Tkinter).
* **Lógica:** Bibliotecas nativas `random` e `string`.
